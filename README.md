# Grammar Reduction

Программа для удаления **бесплодных** и **недостижимых** символов из формальных грамматик.

Проект реализует последовательное приведение грамматики:
1. поиск и удаление бесплодных символов;
2. поиск и удаление недостижимых символов;
3. построение итоговой приведённой грамматики.

## Возможности

Программа позволяет пользователю самостоятельно ввести:

- множество терминальных символов;
- множество нетерминальных символов;
- начальный символ грамматики;
- количество правил;
- правила грамматики.

После ввода программа автоматически выполняет анализ грамматики и выводит промежуточные и итоговые результаты.

## Алгоритм работы

### 1. Удаление бесплодных символов

Бесплодным называется нетерминальный символ, из которого невозможно получить цепочку, состоящую только из терминальных символов.

Программа последовательно строит множества:

```text
Y0, Y1, Y2, ...
```

Построение продолжается до тех пор, пока очередное множество не перестанет изменяться.

После этого определяются бесплодные нетерминалы и удаляются все правила, в которых они используются.

### 2. Удаление недостижимых символов

После удаления бесплодных символов программа начинает анализ с начального символа грамматики.

Последовательно строятся множества:

```text
V0, V1, V2, ...
```

Если символ невозможно получить из начального символа `S`, он считается недостижимым.

При определении недостижимых символов учитываются как нетерминальные, так и терминальные символы.

После завершения алгоритма недостижимые символы удаляются из грамматики.

## Пример использования

Исходная грамматика:

```text
G ({a,b,c}, {A,B,C,D,E,F,G,S}, P, S)

S -> aAbB|E
A -> BCa|a
B -> ACb|b
C -> A|B|bA|aB|cC|aE|bE
D -> c|Fb|Fa
E -> Ea|Eb|Ec|ED|FG|DG
F -> BC|AC|DC|EC
G -> Ga|Gb|Gc|GD
```

После запуска программы необходимо последовательно ввести данные:

```text
Введите терминалы через пробел:
a b c

Введите нетерминалы через пробел:
A B C D E F G S

Введите начальный символ:
S

Введите количество строк с правилами:
8
```

После этого вводятся правила:

```text
S -> aAbB|E
A -> BCa|a
B -> ACb|b
C -> A|B|bA|aB|cC|aE|bE
D -> c|Fb|Fa
E -> Ea|Eb|Ec|ED|FG|DG
F -> BC|AC|DC|EC
G -> Ga|Gb|Gc|GD
```

Программа определит:

```text
Бесплодные символы: [E, G]
Недостижимые символы: [D, F]
```

И выведет итоговую грамматику:

```text
S -> aAbB
A -> BCa | a
B -> ACb | b
C -> A | B | bA | aB | cC
```

## Формат ввода правил

Правила вводятся в формате:

```text
A -> aB|bC|c
```

Альтернативные правые части разделяются символом `|`.

Например:

```text
S -> aAB|E
```

соответствует двум правилам:

```text
S -> aAB
S -> E
```

## Требования

- Java 17 или новее;
- IntelliJ IDEA или другая среда разработки с поддержкой Java.

## Запуск

1. Открыть проект в IntelliJ IDEA.
2. Запустить класс `Main`.
3. Ввести терминалы.
4. Ввести нетерминалы.
5. Указать начальный символ.
6. Указать количество строк с правилами.
7. Ввести правила грамматики.
8. Получить результат приведения грамматики.

## Результат работы

Программа выводит:

- исходную грамматику;
- множества `Y` для поиска бесплодных символов;
- найденные бесплодные символы;
- грамматику после их удаления;
- множества `V` для поиска недостижимых символов;
- найденные недостижимые символы;
- итоговую грамматику;
- итоговое множество терминалов;
- итоговое множество нетерминалов;
- начальный символ грамматики.
